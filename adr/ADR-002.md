# ADR-002 — Hexagonal Architecture

Estado: Accepted

Fecha: 2026-08-16

## Contexto

El dominio debe permanecer independiente de frameworks, transporte,
persistencia y servicios externos.

## Decisión

Adoptar Hexagonal Architecture. Application expone input ports y utiliza
output ports; Domain contiene el modelo de negocio; inbound y outbound
adapters permanecen fuera del núcleo.

Todas las dependencias de código apuntan hacia Domain/Application.

## Consecuencias

- Repository Contracts son puertos y sus implementaciones adapters;
- HTTP, CLI y consumidores de mensajes son inbound adapters;
- bases de datos, brokers, FIWARE, NGSI-LD e Identity Providers son
  outbound adapters;
- ningún detalle técnico modifica el lenguaje o las invariantes.
