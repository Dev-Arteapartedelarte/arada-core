# ADR-003 — Domain and Integration Event Boundaries

Estado: Accepted

Fecha: 2026-08-16

## Contexto

La documentación mezclaba hechos internos con contratos públicos y
permitía consumo directo entre Bounded Contexts.

## Decisión

Un Domain Event es interno al Bounded Context productor. El Aggregate lo
genera y registra; Application coordina su publicación después del commit.

Todo cruce de frontera utiliza un Integration Event o API Contract
explícito, con payload y versión independientes. La conversión desde un
Domain Event nunca es automática.

## Consecuencias

- Notification y Audit reciben contratos por adapters y ejecutan Commands
  propios;
- brokers, outbox, retries y deduplicación son decisiones posteriores;
- Event Sourcing continúa siendo compatible, pero no obligatorio.
